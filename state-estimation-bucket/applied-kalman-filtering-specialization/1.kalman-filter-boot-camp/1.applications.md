## Model-Based State Estimation

- KFs use sensed measurements and a mathematical model of a dynamic system to estimate its internal hidden state.
- A model of the system and its state dynamics is assumed to be known
- A systems state is a vector of values that completely summarizes the effects of the past of the system.
- Model's state should mirror system's state

## Why a Model?

- We cannot generally measure the state of a dynamic system directly. Even when we can, we often choose to not do so because it is too expensive or too complex.

- Instead we measure the system input and then propagate those measurements through the model. updating the model's prediction of the true state

- We make measurements that are linear or nonlinear functions of members of the state.
- The measured and predicted outputs are compared.
- The KF is an algorithm that updates the model's state estimate using this prediction error as feedback regarding the quality of the present state estimate.

Linear KFs use discrete-time state-space models of the form:

$$x_{k+1}= Ax_k + Bu_k + w_k$$

$$z_k = Cx_k + Du_k + v_k $$

Where,

- $x_k$ is the system state vector
at time index $k$.

- $u_k$ is the measureable or deterministic input to the system.

- $w_k$ is the disturbance or process noise: an unmeasurable input that affects the state.

- $z_k$ is a sensor measurement, somehow related to $x_k$

- $v_k$ is sensor noise that currpts the measurement.

- $A, B, C, D$ are matrices that describe the specific system we are observing.

Output Equation -> How measured output relates to the state

## Why Feedback?

Discrete-time Kalman filters repeatedly execute two steps:

1. Predict the present state-vector past available data.

2. Estimate the present state value by updating the prediction based on all presently available data.
