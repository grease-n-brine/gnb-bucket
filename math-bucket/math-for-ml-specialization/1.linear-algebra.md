# Introduction to Linear Algebra

## Vectors

Use calculus to optimize some form of loss (i.e. Gaussian distribution) to find $\mu$ (center of the distribution) and $\sigma$ (width of the distribution) with the best fit to the data.

$\mu$ and $\sigma$ can be represented in a parameter space, where plotting each value in a vector space describes a set of possible characteristics of these variables.

## Vector Operations

Order does not matter in additions.
